ИСПРАВЛЕНИЕ МОНИТОРИНГА ТЕСТИРОВАНИЯ

1) Откройте Google Таблицу, в которую СЕЙЧАС записываются новые тесты.
   Скопируйте её ID из адреса: https://docs.google.com/spreadsheets/d/ID/edit
2) В редакторе Apps Script замените старый код содержимым testadmin-server.gs.
   В строке SPREADSHEET_ID = "" укажите ID таблицы. Проверьте SHEET_NAME = "Ответы".
   При необходимости смените ADMIN_KEY одновременно с паролем администратора.
3) Apps Script: Развернуть → Управление развертываниями → Изменить (карандаш)
   → Версия: Новая версия → Развернуть. Это обязательно: сохранения кода недостаточно.
   Если создадите НОВОЕ развёртывание, замените SCRIPT_URL в index.html,
   а также в сайте тестирования, если он использует тот же endpoint.
4) В GitHub в папку testadmin добавьте testadmin-sync.js.
   В файле testadmin/index.html добавьте ПОСЛЕ основного </script> и ПЕРЕД </body>:
   <script src="./testadmin-sync.js?v=1"></script>
5) Для календаря добавьте в ту же папку testadmin-dates.js, затем после sync:
   <script src="./testadmin-dates.js?v=2"></script>
6) Перезагрузите сайт Ctrl+F5. Проверьте строку «Источник: ...».
   Имя таблицы, имя листа и дата последней записи должны соответствовать
   новой таблице и последнему пройденному тесту.

ВАЖНО: исходный Apps Script не ограничивает чтение датой 01.11.2026.
Если новые записи есть в таблице, но сайт остановился на этой дате,
особенно вероятны устаревшее развёртывание либо подключение не той таблицы.
Скрипт диагностики покажет название таблицы, листа и последнюю дату.

НЕ ДОБАВЛЯЙТЕ этот скрипт в постороннюю таблицу: он должен продолжать
обслуживать приём результатов с сайта участников тестирования.
