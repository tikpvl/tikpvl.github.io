СЕМИНАР · 6 ГРУПП

ФАЙЛЫ
index.html — ноутбуки групп, ввод номера от 1 до 6.
admin.html — компьютер оператора, выбор группы / все группы / заставка.
display.html — отдельное окно для LED-экрана без управляющих кнопок.

ПРОВЕРКА НА ОДНОМ КОМПЬЮТЕРЕ
Запустите локальный сервер в папке (Windows: py -m http.server 8000).
Откройте http://localhost:8000/admin.html, /display.html и /index.html в отдельных вкладках.
Без Firebase работает ЛОКАЛЬНОЕ ДЕМО между вкладками одного браузера. Оно НЕ соединяет разные ноутбуки.

ДЛЯ РЕАЛЬНОЙ РАБОТЫ НА 7 КОМПЬЮТЕРАХ
1. Создайте проект Firebase и Realtime Database.
2. Вставьте параметры проекта и URL базы в config.js.
3. Настройте Firebase Authentication и правила доступа к Realtime Database перед публичным запуском. Текущий пример не включает безопасную авторизацию: номер группы — это выбор, не защита доступа. Не оставляйте базу с открытыми правилами на публичном домене.
4. Разместите папку на GitHub Pages (например, tikpvl.asia/seminar/).
5. На компьютере оператора откройте admin.html, на LED — display.html в отдельном окне и нажмите F11. В Windows выберите «Расширить эти экраны», перетащите окно на LED.
6. На шести ноутбуках откройте index.html и введите номера групп.

ВАЖНО: Для защищённого публичного семинара требуется добавить авторизацию Firebase и правила, ограничивающие запись ответов каждой группы. До этого используйте только локальную демонстрацию. Если интернет/база недоступны, межкомпьютерная синхронизация не работает. Ответы передаются с короткой задержкой ~100 мс плюс сеть, не гарантированно мгновенно.

Материалы: шесть кейсов из предоставленного документа. Готовые ответы не включены.
